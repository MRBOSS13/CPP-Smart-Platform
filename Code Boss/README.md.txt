# 🚀 منصة المبرمج الذكي (C++ Smart Platform)

منصة تفاعلية متكاملة ومجانية بلغة C++ موجهة للطلاب والمبرمجين المبتدئين لكسر حاجز اللغة الإنجليزية، وتسهيل تعلم البرمجة واستكشاف الأخطاء وتوثيق الأكواد خطوة بخطوة.

## 🌟 الميزات الأساسية
- **المساعد الذكي (AI Assistant):** توليد هيكل برمجية وأكواد جاهزة بناءً على فكرة المستخدم.
- **فاحص الأخطاء الذكي (Error Bank & Line Detection):** تحديد مكان السطر البرمجي وعرض سبب الخطأ وحله باللغة العربية.
- **بيئة الألعاب والتفاعل (Game Sandbox):** محاكاة خوارزميات التتبع والذكاء الاصطناعي في الألعاب.
- **نظام توليد التعليقات (Auto-Doc):** إضافة تعليقات شرح باللغة العربية للأوامر البرمجية تلقائياً.
- **إدارة السجلات (File Manager):** حفظ سجلات النشاطات والمشروعات في ملفات نصية خارجية (`.txt`).

## 📁 هيكلية المشروع (Modular Structure)
- `main.cpp`: نقطة انطلاق القوائم والواجهة الرئيسية.
- `AIAssistant.h`: كلاس المساعد الذكي.
- `ErrorBank.h`: كلاس فاحص الأخطاء ومحدد السطر.
- `GameSandbox.h`: كلاس بيئة الألعاب التفاعلية.
- `AutoDocSystem.h`: كلاس التوثيق والتعليقات التلقائية.
- `FileManager.h`: كلاس حفظ وقراءة البيانات من الملفات.

## 🛠️ كيفية التشغيل
قم بتجميع الكود باستخدام أي مترجم C++ (مثل `g++` أو IDE مثل Dev-C++ / VS Code):
```bash
g++ main.cpp -o SmartPlatform
./SmartPlatform
